# Stack icons and typography

Brand icon paths: [Simple Icons](https://github.com/simple-icons/simple-icons), [CC0-1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md). Brand names and logos belong to their respective owners.

Headings use M PLUS Rounded 1c Bold, matching the portfolio. Text is converted to SVG paths so it renders consistently without remote font requests.
